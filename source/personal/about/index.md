## 4.技术栈&框架🧪

<div class="ab2">
  <p class="ab2-lead">按「请求从哪进来 → 页面怎么生成 → 浏览器里跑什么 → 产物怎么构建发布 → 数据存在哪 → 授权怎么给」拆成六层。<b>版本号均为当前实际安装版本</b>，不是官网最新版。</p>
  <div class="ab2-stack">
    <div class="ab2-layer">
      <div class="ab2-layer-h"><span class="ab2-layer-idx">L1</span><span class="ab2-layer-name">接入与边缘</span><span class="ab2-layer-en">Ingress / Edge</span></div>
      <ul class="ab2-layer-body">
        <li><b>边缘网络</b><a href="https://www.cloudflare.com/zh-cn/" target="_blank" rel="noopener">Cloudflare</a>（主站 + 图床） · <a href="https://vercel.com/" target="_blank" rel="noopener">Vercel</a>（评论服务）</li>
        <li><b>传输层</b>全站强制 HTTPS，Cloudflare 侧已开放 <b>HTTP/3</b>（<code>alt-svc: h3=":443"</code>），静态资源与页面同源</li>
        <li><b>图片</b>独立图床域名，站内图片全部 <code>loading="lazy"</code> + <code>vanilla-lazyload</code> 兜底，不进首屏关键路径</li>
        <li><b>CDN 源</b><a href="https://registry.npmmirror.com/" target="_blank" rel="noopener">npmmirror</a> · <a href="https://cdn.jsdelivr.net/" target="_blank" rel="noopener">jsDelivr</a> · <a href="https://cdn.jsdmirror.com/" target="_blank" rel="noopener">jsdmirror</a> · <a href="https://www.iconfont.cn/" target="_blank" rel="noopener">阿里矢量图标库</a></li>
      </ul>
    </div>
    <div class="ab2-layer">
      <div class="ab2-layer-h"><span class="ab2-layer-idx">L2</span><span class="ab2-layer-name">站点生成与渲染</span><span class="ab2-layer-en">SSG / Renderer</span></div>
      <ul class="ab2-layer-body">
        <li><b>生成器</b><a href="https://github.com/hexojs/hexo" target="_blank" rel="noopener">Hexo 6.3.0</a>（Node.js 静态站点生成，全量构建约 1 秒）</li>
        <li><b>Markdown</b><code>hexo-renderer-markdown-it 6.1.0</code> 与 <code>@upupming/hexo-renderer-markdown-it-plus 2.0.2</code> 双渲染器注册（plus 先注册、markdown-it 后注册生效）</li>
        <li><b>模板 / 样式</b><a href="https://pugjs.org/" target="_blank" rel="noopener">Pug 3.0.0</a> · <a href="https://stylus-lang.com/" target="_blank" rel="noopener">Stylus</a> · EJS · YAML</li>
        <li><b>主题</b>Fomalhaut 1.0.5，基于 <a href="https://butterfly.js.org/" target="_blank" rel="noopener">Butterfly 4.3.1</a> 二次开发，源码已开源：<a href="https://github.com/MuyuDada/hexo-theme-fomalhaut" target="_blank" rel="noopener">hexo-theme-fomalhaut</a></li>
        <li><b>内容插件</b><code>markdown-it-container / -deflist / -emoji / -mark</code> · <code>hexo-abbrlink</code>（固定链接） · <code>hexo-blog-encrypt</code>（文章加密） · <code>hexo-wordcount-fomal</code>（字数统计） · <code>hexo-filter-nofollow</code> · <code>hexo-filter-gitcalendar</code></li>
        <li><b>聚合与订阅</b><code>hexo-generator-index / archive / category / tag</code> · <code>hexo-generator-sitemap</code> · <code>hexo-generator-feed</code> · <code>hexo-generator-search</code>（本地搜索索引）</li>
      </ul>
    </div>
    <div class="ab2-layer">
      <div class="ab2-layer-h"><span class="ab2-layer-idx">L3</span><span class="ab2-layer-name">前端运行时</span><span class="ab2-layer-en">Client Runtime</span></div>
      <ul class="ab2-layer-body">
        <li><b>无刷新路由</b><a href="https://github.com/defunkt/jquery-pjax" target="_blank" rel="noopener">Pjax</a> 0.2.8（换页不整页刷新，自写脚本统一监听 <code>pjax:complete</code> 重新初始化）</li>
        <li><b>资源加载</b><code>vanilla-lazyload</code> 图片懒加载；jQuery + 本地兜底 <code>/js/jquery.min.js</code>（CDN 失效不断链）</li>
        <li><b>交互组件</b>自研零依赖轻量通知组件 <code>/js/notify.js</code>，替换掉原 Element-UI + Vue 方案（省下约 813 KB 同步 CSS/JS）</li>
        <li><b>评论</b><a href="https://waline.js.org/" target="_blank" rel="noopener">Waline</a> 2.6.1，自托管在 Vercel，支持 Markdown、表情、登录与访客计数</li>
        <li><b>搜索</b><code>hexo-generator-search</code> 生成本地索引 <code>/search.xml</code>，前端按需加载、无第三方请求</li>
        <li><b>音乐 / 媒体</b><a href="https://github.com/MoePlayer/hexo-tag-aplayer" target="_blank" rel="noopener">hexo-tag-aplayer</a> + <a href="https://github.com/metowolf/MetingJS" target="_blank" rel="noopener">MetingJS</a></li>
      </ul>
    </div>
    <div class="ab2-layer">
      <div class="ab2-layer-h"><span class="ab2-layer-idx">L4</span><span class="ab2-layer-name">构建与自动化交付</span><span class="ab2-layer-en">Build / CI-CD</span></div>
      <ul class="ab2-layer-body">
        <li><b>构建链</b><a href="https://github.com/gulpjs/gulp" target="_blank" rel="noopener">gulp 4.0.2</a> → <code>gulp-html-minifier-terser</code> · <code>gulp-htmlclean</code> · <code>gulp-clean-css</code> · <code>gulp-terser</code></li>
        <li><b>一键部署</b><code>npm run deploy:vercel</code> → <code>tools/deploy-vercel.js</code> 依次跑 <code>hexo clean / generate / deploy</code></li>
        <li><b>发布</b><a href="https://github.com/features/actions" target="_blank" rel="noopener">GitHub Actions</a> + <code>hexo-deployer-git</code>，产物推给托管商后由边缘网络分发</li>
        <li><b>回滚</b>站点是纯静态产物，出问题直接回退上一次构建的 commit 重新发布即可</li>
      </ul>
    </div>
    <div class="ab2-layer">
      <div class="ab2-layer-h"><span class="ab2-layer-idx">L5</span><span class="ab2-layer-name">数据与可观测</span><span class="ab2-layer-en">Data / Observability</span></div>
      <ul class="ab2-layer-body">
        <li><b>评论数据</b>Waline 服务端持久化，文章页 / 留言板 / 打赏页共用同一套数据</li>
        <li><b>访问统计</b><a href="https://aoaoao.info/321.html" target="_blank" rel="noopener">不蒜子</a>（前端 UV/PV） + <a href="https://v6.51.la/" target="_blank" rel="noopener">51la</a>（访问趋势与来源），另有 <a href="/site/census/">网站统计</a> 页汇总</li>
        <li><b>性能</b>站点 JS 全部 <code>defer</code>，不进首屏关键路径；自写脚本按需加载（如搜索、ECharts、标签关系图）</li>
        <li><b>友链朋友圈</b><a href="https://github.com/Rock-Candy-Tea/hexo-circle-of-friends" target="_blank" rel="noopener">hexo-circle-of-friends</a> 爬虫由 GitHub Actions 定时跑，产出静态 JSON 后交 jsDelivr 分发</li>
      </ul>
    </div>

    <li><b>改成 Fomalhaut</b>：把改动攒成一个能独立分发的主题，配置全抽到 <code>_config.fomalhaut.yml</code>，站点侧只留 <code>source/css</code> 与 <code>source/js</code>，升级主题不会冲掉自己的改动。</li>
    <li><b>现在</b>：主题和站点一起演进，页面、小部件、脚本都开源在 <a href="https://github.com/MuyuDada/hexo-theme-fomalhaut" target="_blank" rel="noopener">GitHub</a> 上。</li>
  </ol>
